# 新手入门

[English](QUICKSTART_EN.md) · [用户手册](GUIDE.md) · [返回首页](../README.md)

这份指南从空人物列表开始，带你完成服务配置、人物创建和第一次聊天，再使用语音、照片及保存功能。新安装不包含演示人物、照片或定制音色；请准备本人、明确授权或原创虚构的资料。完整功能与配置说明以[用户手册](GUIDE.md)为准。

## 1. 启动应用

按[安装说明](GUIDE.md)运行桌面启动器或源码脚本，打开启动器显示的本机地址。保留启动器或服务终端运行；不要直接打开项目里的 HTML 文件。

**完成标志：** 浏览器出现人物首页。若之前的人物不见了，先核对启动器的数据目录：源码版与桌面版默认使用不同目录。

## 2. 先接通对话服务

准备服务商账号、可用模型和 API Key。云端分析、对话、看图、合成及生成可能产生费用；浏览器语音识别也可能使用浏览器自己的在线服务。

1. 打开“全局 AI 设置 → 服务与能力路由”，新建连接。
2. 填写服务、地址及专门的 API Key 字段；密钥不要放进人物设定、URL 或高级 JSON。
3. 先开启“对话”，填入服务支持的模型并授权发送文字，保存连接。
4. 为“对话”能力选择这条连接和模型，保存路由；检查连接已启用。
5. 在“能力状态”查看就绪条件；如有错误，在“诊断中心”核对密钥、模型、授权、预算和服务商余额。

想让人物出声，再配置“语音合成”；想让人物看照片，再配置“视觉理解”并授权图片。浏览器识别式语音消息和语音通话不要求先配置文件“语音转写”。

**完成标志：** 连接和路由保存后仍可查到，所需能力显示具备条件。连接检查通过不等于所有功能都已实际调用成功；第5节的回复才是首次对话结果。

预算使用估算，不能保证实际账单封顶。统一服务中心的声音复刻有专门的估价与调用前预算检查；旧阿里云兼容路径没有同等检查。复刻前阅读[费用及数据边界](PRIVACY.md)。

## 3. 创建人物并完成必须项

首次体验可从原创虚构人物开始；已有获授权的真人资料则选择“从真实素材创建”。

1. 首页点击“创建虚构数字人”，填写姓名、关系、语言、世界场景及资料使用权。
2. 按问答填写身份、性格、说话方式和边界，每项保存。不需要的复杂世界模块可暂时跳过。
3. 点击“选择 AI 方式”，使用已配置的连接；阅读整理出的档案，修正后“保存并继续”。如分析页要求连接，先完成第2节。
4. 进入人物工作室的“构建中心”，点击“检查设定”，按提示补齐必须项。需要更新构建结果时使用“运行统一 Builder”。
5. 确认人物显示“正式可用”，再进入日常聊天。推荐和高级项可稍后补充。

**完成标志：** 人格资料符合填写内容，必须项通过且显示“正式可用”。该状态由检查结果决定，没有单独的“启用人物”按钮。仍是“预览测试模式”时，查看缺少的是资料还是模型；预览聊天与正式聊天分开保存。

## 4. 已有资料、照片和音色怎么用

不同文件有不同用途，请按内容选择入口：

| 内容 | 操作 | 完成后检查 |
|---|---|---|
| 人物设定文件 | 虚构路线选择“导入已填写模板”；在“检查内容”核对字段及合并/覆盖方式，再“确认并用于构建” | 人物摘要、表达方式、边界及世界设定 |
| 聊天记录 | 真实素材路线的“聊天记录”上传；检查说话人、排除无关条目后确认 | 已确认历史、证据与记忆 |
| 整个人物包 | 首页导入 `.openavatar.zip`，阅读预检并确认资料使用权 | 新导入人物及其包含的内容 |

已有虚构人物可从“人格与资料 → 继续导入资料”补充设定。虚构设定路线不提供同样的聊天记录上传入口；不要把聊天记录当成人物模板导入。下载的双格式模板要单独取 Markdown 或 YAML 部分保存再填写，也可直接使用仓库的 [Markdown](templates/avatar.md) 或 [YAML](templates/character.yaml) 模板。

**使用自己的照片：** 从资料上传页的视觉候选或照片入口上传，到“构建中心”检查候选，满意后“批准”，再将主身份图“设为 canonical”（固定主要身份参考）。有合适照片时无需重新生成。聊天里的照片与身份参考图用途不同。

**选择声音：** 配好 MiniMax 语音合成路由后，在构建中心选择服务支持的预置音色。选择本身不调用云端、不等于声音复刻；播放回复会合成声音并计费。新安装不会自动提供别人演示中使用的定制音色。

**完成标志：** 导入内容已经确认、能在相应资料中看到；主身份图为 canonical，目标音色已选中。上传完成不等于批准，选中音色不等于试听通过。

## 5. 发出第一条正式消息

1. 打开“对话”，输入一句能检查设定的短问题，点击“发送”。
2. 看回复逐步出现，核对人物身份和表达方式；普通文字与语音消息回复最多80个字符，包含标点。
3. 需要朗读时点击回复旁的播放，并处理费用确认。只阅读文字不需要语音合成。
4. 返回首页再打开同一人物，检查刚才的消息和回复仍然存在。

**完成标志：** 人物给出完整回复，正式聊天记录可重新打开。出错时先读提示、检查路由和额度，再决定重试，避免连续发送重复请求。

## 6. 使用语音、照片和“＋”面板

| 想做什么 | 实际步骤 | 成功判断与边界 |
|---|---|---|
| 发语音消息 | 输入框左侧切换麦克风；按住说话，松开发送；仍按住时上滑再松开可取消 | 语音条可回听；识别出文字才请求人物回复。无文字时只保存录音，可补发文字。少于0.5秒不发，最长60秒 |
| 自拍或发照片 | “＋ → 拍摄”或“图片 / 视频”；自拍默认镜像，可关闭；检查预览后发送 | 预览和发送方向一致。有视觉理解路由时会读取照片并回复，可能计费；仅保存照片不等于看图成功 |
| 再看历史照片 | 点击照片旁的“让她看图” | 成功后显示已看图；成功结果复用，失败需手动重试。聊天看图与资料 OCR 独立 |
| 发视频或文件 | “＋ → 图片 / 视频”或“文件”，预览后发送 | 视频可播放，文件可下载；目前不自动理解内容 |
| 发位置 | “＋ → 位置”，填写名称与地址后发送 | 显示手动填写的位置卡，不自动定位或持续共享 |
| 收藏和重发 | 点消息旁的 ☆，再从“＋ → 收藏”选择并发送 | 收藏中能找到原内容，聊天出现重发消息 |

单个附件最多50 MB，并受当前上传设置限制。照片发到聊天不会自动成为人格资料。语音或摄像头不可用时，检查浏览器站点权限；浏览器不支持识别时可以改用文字。

## 7. 进行语音通话

先确认对话和语音合成可用、已选音色，并允许麦克风。建议戴耳机。

1. 在聊天输入区选择“＋ → 通话 → 语音通话”，阅读本次说明，点击“开始通话”。
2. 说一句话，等待人物回复；需要改变话题时直接开口，或点击“打断回复”，再说新的内容。
3. 点击麦克风按钮可静音/恢复；点击“—”最小化，点击小窗返回。
4. 点击“挂断”，检查聊天中出现本次通话卡片。

**完成标志：** 能听到所选音色，打断后停止旧回复并接续新内容，静音和窗口状态正确，挂断后停止录音。每次最多3轮、10分钟；隐藏页面或切换人物会结束通话。

通话窗口及普通聊天历史不展示双方逐句通话文字，但文字仍在本机保存并可用于后续模型上下文。普通语音消息仍正常显示。视频通话位于同一“通话”菜单，需要单独的 North/Atlas 配置，不属于完成首次语音通话的前提。

## 8. 保存、迁移与后续整理

1. “设置与导出 → 导出完整人物包”，选择对话、音频、图片、视频和通话记录，再生成并下载。
2. 检查得到 `.openavatar.zip`；迁移时在首页导入，阅读预检并确认使用权，随后检查设定及所选素材。
3. 密钥不随人物包迁移；外部声音或视觉资产可能需要重新绑定服务。

**完成标志：** 包已下载且可通过预检，重新导入的人物及所选内容能打开。关闭“通话记录”会排除通话文字、卡片、会话和回复诊断；旧合成音频未区分用途，因此也会排除包括旧试听在内的合成音频。原始录音和语音消息附件仍由音频选项控制。

人物包不能替代完整数据库备份。“设置与导出 → 数据维护”可创建数据库备份、修改/批准记忆、合并重复项并查看修订记录；“人生档案”可修改运行聊天、封存及恢复版本。数据库恢复影响当前数据目录的全部人物，并要求输入确认文字，恢复前会创建安全备份；它不替换素材文件或系统凭据。操作细节见[用户手册](GUIDE.md)和[人物包协议](OPENAVATAR_PACKAGE.md)。

声音复刻、世界事实审批、服装/场景连续性素材和异步视频属于后续进阶功能，可按需要再配置。无需为了完成入门而开启所有服务或重新生成已有满意素材。
