# 用户手册

[English](GUIDE_EN.md) · [返回首页](../README.md)

本手册对应 0.1.0 发布候选。新安装没有预置人物；服务商账号、模型和权重需要用户自行准备。没有模型连接时，仍可导入资料、编辑设定和进行离线人格初步分析。

## 安装与启动

### 源码版

准备 Python 3.11+，下载并解压源码。macOS 双击 `start.command`，Windows 双击 `start.bat`，Linux 执行 `chmod +x start.sh` 后运行 `./start.sh`。首次启动创建 `.venv` 并安装依赖，之后仍会检查依赖版本。安装失败时先解决终端错误再启动。

默认打开 `http://127.0.0.1:8767`。可通过 `PORT` 环境变量选择其他端口；手动打开浏览器时要使用实际端口。关闭启动服务的终端会停止服务。直接打开 HTML 文件只会显示静态页面，无法使用后端能力。

开发环境安装与测试见[贡献指南](../CONTRIBUTING.md)。

### 桌面版

从 [Releases](https://github.com/Mindy2000/OpenAvatar-Studio/releases) 下载与你的操作系统及处理器架构匹配的软件包。桌面包已包含 Python，无需另装。完整解压后运行 macOS 的 `OpenAvatar Studio.app`、Windows 的 `OpenAvatar Studio.exe`，或 Linux 目录内的 `OpenAvatar Studio`。

桌面启动器运行本机服务并打开浏览器，不是内嵌浏览器的原生编辑器。它从 8767 起寻找可用端口，窗口显示实际地址和数据目录。退出启动器可停止服务。当前包未做正式签名，系统可能提示未知发布者；只有确认来源后再依照操作系统提示处理。打包和平台验收见[发布指南](../packaging/README.md)。

### 数据目录

| 启动方式 | 默认位置 |
|---|---|
| 源码脚本 / 直接运行服务 | 项目内 `data/` |
| macOS 桌面版 | `~/Library/Application Support/OpenAvatar Studio/` |
| Windows 桌面版 | `%LOCALAPPDATA%/OpenAvatar Studio/` |
| Linux 桌面版 | `$XDG_DATA_HOME/openavatar-studio/`，未设置时使用 `~/.local/share/openavatar-studio/` |

`OPENAVATAR_DATA_DIR` 可以覆盖位置。数据库为 `openavatar.sqlite`，人物文件在 `avatars/`，导出在 `exports/`。两种启动方式不会自动合并各自的数据；若需要迁移，请使用人物包或在理解数据目录作用后配置路径。

## 第一次使用

1. 阅读新手向导，选择真实素材或虚构设定路线。
2. 填写身份、语言、世界地区和授权信息。
3. 打开“全局 AI 设置”，优先在“服务与能力路由”配置服务。
4. 在“能力状态”和“诊断中心”确认当前配置与数据去向。
5. 进入人物工作室的构建中心，按必须项和下一步建议完善资料。

界面语言与人物输出语言分开设置。人物可以使用中文、英文、混合或自定义语言；地区可选择中国大陆、北美、日本、欧洲或自定义。地区影响世界运行规则，不代表系统已经接入当地实时新闻或天气。

## 服务与能力路由

设置页包含“服务与能力路由”“旧版模型连接”“截图 OCR”和“声音 / 视觉 / 视频”。新服务中心可保存 MiniMax、阿里云、OpenRouter、OpenAI 兼容、本地服务或 North/Atlas 连接，并为每项能力选择主服务、备用服务和模型。

云端连接按文字、音频、声音生物特征、图片、视频等数据类型授权。API Key 应填在专门的密钥字段，不要写入高级 JSON、URL、人物设定或聊天内容。高级配置和连接地址属于普通元数据，不能当作安全密钥容器。

“本地”服务只接受 `127.0.0.1`、`localhost` 或 `::1`，例如 `http://127.0.0.1:1234/v1`。保存及使用时均检查地址，本地模型请求不使用系统代理且拒绝重定向。此前保存的外网地址会被拒绝，需改为正确的本机地址。详见[隐私说明](PRIVACY.md)。

旧版模型连接用于兼容已有设置，支持云端 OpenAI 兼容、本地 OpenAI 兼容、Ollama 和本地适配器。旧流程使用连接测试状态；新能力路由没有统一执行“7 天内测试成功”门槛。部分纯媒体连接的测试不实际调用生成接口，“测试成功”不等于声音、图片或视频已端到端可用。

预算是基于用量记录的估算。MiniMax 部分能力有默认估算，其他服务若没有配置 `cost_estimates` 可能按 0 记录。预算不能代替服务商账户上的费用限制，模型可用性与计费以服务商为准。

## 真实素材路线

仅为本人或明确授权对象创建人物。人格需要文字或聊天资料，音频不能单独形成人格。声音样本用于声音流程，图片用于视觉候选。

聊天支持 TXT、Markdown、JSON、JSONL、CSV、TSV。文本可写为 `名字: 内容`；表格/JSON 常用 `speaker`、`role`、`sender`、`name` 和 `content`、`text`、`message` 等字段。导入后检查说话人、逐条排除内容，再确认进入证据与记忆。

图片可保存 PNG、JPEG、WebP、HEIC；元数据在可处理时移除，不能假定所有格式都已去掉 EXIF/GPS。没有可用 OCR 时可手动补文字。若选择了云端 OCR，上传图片会直接使用该连接，不会逐张再次弹窗确认；敏感图片上传前先检查 OCR 配置。

音频支持 WAV、MP3、M4A、AAC、OGG、FLAC。构建中心提供样本检查、授权、ASR/人工转写确认、服务选择、复刻任务和声音档案。付费操作需要界面确认。默认声音列表中的 Piper 条目只是开发期候选，没有随项目打包模型或完整本地播放引擎；选择一个候选不等于已经完成声音复制。

## 虚构设定路线

普通用户可用问答式 Builder；高级用户可导入 Markdown、TXT、JSON、YAML。解析器处理人物设定，不是通用 YAML 执行器，不支持任意脚本。

“下载模板”会得到 `openavatar-character-templates.txt`，其中用分隔线串联 Markdown 与 YAML 两份模板。请分别保存需要的部分为 `.md` 或 `.yaml` 后填写和导入，不要将整份拼接文件当作一个 YAML 文档。

仓库中的 [Markdown 模板](templates/avatar.md) 和 [YAML 模板](templates/character.yaml) 与当前接口内容一致，来源为 `services/templates.py`。模板中的空白对话字段用于填写人物风格，不包含可导入的演示人物。复杂里世界模块可继续通过 Builder 与世界页面配置；导入后务必检查实际提取结果。

模板 `visual_identity.status: draft` 是设定草稿标记；已登记视觉素材 API 使用 candidate、approved、canonical、rejected、retired，不使用 draft。

## 构建、聊天和人生档案

构建中心分必须、推荐、高级三层。必须项未齐全时只能预览测试；推荐和高级项用于完善声音、视觉、记忆规模与评估。离线分析、参考图生成和真实训练不同，不能把参考图身份保持称为模型微调。

人物工作室可以编辑人格、边界、世界事实和反馈规则。世界支持生活时钟、事件、资源、快照、审批、回滚与冲突检查。高影响变化应经用户审核。

文字聊天支持流式输出和取消。导入历史与启用后的运行聊天分层管理：导入原文不被时间线编辑覆盖，历史校正以显示层叠加；运行聊天可搜索、修改、封存和恢复。修改或删除会封存选中位置之后的相关聊天及可追溯的共同变化，恢复会互换时间线。永久清除封存分支前创建数据库备份。预览与正式时间线分开。

主动联系默认关闭，只在服务运行期间按设置写入本机聊天时间线。可以设置次数、时段、冷却和话题，不会发送短信、邮件或其他平台消息。开启云端模型时仍可能产生调用费用。

## 声音、视觉与视频

声音复刻和聊天语音播放需要可用的服务与已激活资产；ASR 转写可由服务或人工确认。实时 WebSocket 通话网关当前支持文字驱动的流式交流和插话取消，二进制音频输入会提示尚未配置实时 ASR；不能把普通文件转写与实时麦克风识别混为一谈。

参考图先成为候选，经用户确认再进入 approved/canonical。可按人物、服装、物品、场景组织连续性素材包。生成照片/视频使用相应参考合同；视频完成后下载、抽取关键帧并审核。关键帧提取依赖本机 FFmpeg；没有可用审核能力时需要人工验收。

异步视频可使用 MiniMax、OpenRouter 或阿里 WAN，实际首帧、多参考、尾帧、音频等支持取决于所选服务与模型，不存在对所有任务固定的 OpenRouter 主链路。

实时视频通话固定使用 North/Atlas：配置 Key、canonical/approved 身份图或 HTTPS Face URL，再确认开始通话。前端从 CDN 加载 LiveKit SDK、连接远程房间，复刻语音播放时可推送音轨驱动口型。结束时请求释放远程 session；网络失败时需要在服务商侧核查状态和费用。

## 人物包、备份和删除

人物包导出为 v3，可导入 v1/v2/v3。界面分别控制对话、音频、图片、视频、通话记录；导入前在本机预检并确认资料使用权。密钥字段不迁移，外部声音/视觉资产可能需要重新绑定。人物包不是完整数据库备份，也不等同于保存所有时间线分支。见[人物包协议](OPENAVATAR_PACKAGE.md)。

“删除人物”删除当前人物记录和素材目录，不清除已经导出的包、旧数据库备份、其他数据目录或服务商副本。数据库恢复需输入 `RESTORE OPENAVATAR DATABASE`，恢复前创建安全备份。备份和人物包都应按敏感文件保管。

## 常见问题

- 页面只有静态内容：通过启动脚本或桌面启动器打开实际服务地址。
- 依赖安装失败：检查 Python 版本、网络和系统证书；不要关闭 HTTPS 验证来绕过错误。
- 模型不可用：检查运行中的服务、实际地址、模型名称、授权、路由及对应服务的配额。
- 保存 Key 失败：检查系统凭据库是否可用/已解锁。Linux 需要可用的 Secret Service 环境，不能保证无桌面服务器自动具备它。
- 图片没有文字：检查 OCR；Tesseract 及语言包等是可选依赖，没有时可手动输入。
- 视频无法提取关键帧：检查 FFmpeg 与实际视频文件；生成成功不等于通过连续性验收。
- 安装包不可用：先用源码版定位问题；Windows/Linux 桌面体验需要对应平台验收。

完整的数据边界见[隐私说明](PRIVACY.md)，安全反馈见[安全政策](../SECURITY.md)。
