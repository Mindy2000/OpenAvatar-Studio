# 隐私与数据边界

[English](PRIVACY_EN.md) · [用户手册](GUIDE.md)

OpenAvatar 处理聊天、声音、肖像等个人资料。仅导入本人、明确授权或原创虚构内容。源码不附带人物数据或凭据；本机运行产生的文件与公开源码分开。

## 本地保存

源码版默认使用项目 `data/`，桌面版使用各系统应用数据目录，`OPENAVATAR_DATA_DIR` 可覆盖位置。各平台路径见[用户手册](GUIDE.md)。目录内包含 SQLite 数据库、人物素材、生成文件、导出和备份。

项目忽略规则排除默认个人数据路径、数据库、人物包、`.env` 和构建产物。自定义数据目录若放到其他源码路径，必须自行检查忽略规则。不要把整个本地目录或 `.git` 当作干净源码上传。

## API Key

专用 Key 字段经本机后端保存到操作系统凭据库；正常连接返回是否配置 Key，不回显该字段。macOS、Windows、Linux 的可用性取决于对应凭据服务。开发者也可通过受支持的环境变量提供 Key；程序不自动读取任意 `.env` 文件。

不要把密钥写入连接 URL、高级配置 JSON、元数据、人物设定、聊天、截图或导入文件。这些属于普通内容，可能保存、显示或导出；程序并非通用秘密识别/脱敏工具。人物包排除的是专用凭据字段，不会识别原始资料中任意形式的秘密。

## 网络与授权

- 标准启动器只监听 `127.0.0.1`。HTTP 写操作和 WebSocket 校验来源；这不是公网多用户鉴权方案。
- 模型分析与聊天可发送人格、相关资料片段、近期对话和检索记忆到所选服务。统一服务中心按能力和数据类型保存授权，主备切换也可能改变接收服务。
- MiniMax、阿里云、OpenRouter 等多模态功能会按服务能力接收文字、音频、图片/参考帧和视频参数。付费媒体任务在界面有确认；确认后后台可能轮询、下载或执行任务重试，不会为每个后台请求重复弹窗。
- **OCR 例外：**选择并授权云端 OCR 后，图片上传会立即使用该连接，不逐张再次确认。上传敏感截图前检查 OCR 设置；可选本地 OCR或手动输入。
- **本地模型连接：**统一服务中心和旧版模型连接只接受 `127.0.0.1`、`localhost`、`::1` 的 HTTP/HTTPS 地址。保存和使用时都会校验；模型发现及本地模型调用不使用系统代理，并拒绝重定向。旧配置中的远程地址也会被拒绝。该限制约束本程序的连接目标；用户安装的本机模型服务是否自行联网，由该服务决定。
- 统一服务中心的“连接测试成功”不证明所有能力都能运行。部分媒体连接测试没有实际生成请求，新路由也未统一执行近期测试门槛。
- 日/月预算比较本机记录的估算费用。没有自定义估算的部分服务记录为 0，不能保证真实账单封顶。
- North/Atlas 通话会传输身份图或 Face URL、房间连接信息和实时轨道。前端还从 CDN 加载 LiveKit SDK。结束时请求释放 session；失败时可能需要自行在服务商处处理。
- **浏览器语音输入：**视频通话页的语音输入按钮使用浏览器 SpeechRecognition，与本系统配置的语音服务和 API Key 独立。明确确认后，浏览器可能把麦克风音频发送到自身的在线识别服务；可用性、处理位置和保留规则由浏览器决定，不保证离线识别。不希望使用该路径时可取消并输入文字。
- 启动脚本安装依赖需要联网。普通用户安装后是否完全离线，取决于模型、OCR、媒体、SDK 等实际配置。

## 人物包与删除

导出可分别关闭对话、音频、图片、视频和通话记录。关闭对话时还排除聊天决策原文、记忆修订、图谱及人格核心缓存。但人格摘要、世界事实、手动输入和其他派生内容仍可能包含个人信息；图片中也可能存在聊天文字。过滤不是匿名化，分享前需要检查文件。

人物包迁移人物内容，不复制系统钥匙串，不是完整数据库备份。导入在本机预检、确认使用权后执行。不要将“清单声明不含 Key”理解成对每段原文都做过秘密扫描。

删除人物会移除当前人物记录和素材目录，**不会删除**：已导出人物包、历史数据库备份、其他数据目录的副本、云端服务持有的资料或操作系统凭据库里的服务连接。永久删除封存时间线也会先备份数据库，旧内容可能存在于备份。

删除确认框会列明保留范围。需要彻底清除个人资料时，仍需另行检查备份、导出、其他数据目录及服务商侧保留政策。

## 日志与材料处理

图片元数据移除是尽力处理，不保证 HEIC 等所有格式均可清理。自定义 OCR 命令以参数列表运行，不通过 shell；只配置可信程序。

诊断、聊天解释、用量记录和运行日志可能包含文件路径、用户输入或服务商错误。分享日志前检查私人内容。软件对专用 Key 字段有隔离设计，但不保证任意外部错误文本都已经脱敏。

各服务商的保留、训练、删除和费用规则由用户选择的服务决定。项目不提供官方云端 API，也不自动替用户撤销第三方已保存的资料。

### 当前进程的凭据缓存

成功从系统凭据库读取的密钥会保留在当前进程内存中，避免刷新页面和并发请求反复触发钥匙串授权；不会另外写入文件或数据库。通过应用更新或删除密钥会同步更新或清除缓存。若从系统钥匙串外部修改密钥，请重启应用以重新读取；退出应用后缓存消失。

## 新增聊天功能的数据去向

聊天图片在发送前的说明及已授权看图路由下交给视觉服务，包含图片像素和人物对话上下文；成功描述及回复保存在本机，失败不自动重试。该路径与构建资料的OCR独立。文件、视频和手动位置卡片不因发送而自动交给多模态服务解读。

未发布的文件提问入口须另外点击“阅读此文件”并确认，才将本机提取的文件文本、问题和当前对话上下文发送给当前对话服务；每次明确提问最多一次调用，不自动重试或切换服务。TXT/MD/CSV限2 MB，文本PDF限10 MB、20页，提取内容总计限20,000字符。没有OCR；超限、加密、无文本或解析失败会拒绝。聊天保存问题、回复和文件来源；普通后续聊天不自动重新附带文件全文，已有默认概括可复用。

语音消息和语音通话也使用浏览器SpeechRecognition，可能由浏览器在线服务识别。识别文字用于模型回复；语音通话的麦克风音量检测只在浏览器本机运行。挂断释放该检测的麦克风轨道。隐藏通话气泡不会删除文字：文字仍存于本机并可进入后续模型上下文。

未发布的分段通话会把每轮最多80字符的回复分成最多3次TTS请求，使用所选音色，按次收费的服务总额可能改变。本次时长及人民币估算额度由服务器检查，达到时长或不足以下一次请求时结束；估算预留不是实际扣款或服务商账单硬上限，失败和打断也不撤销已经发出的请求。不会为了提速自动更换模型或音色，也不自动重试失败请求。本轮未新增真实付费验收结论。

语音通话开始前本机检查音色、连接、授权、凭据存在、估价和预算，不发出云端探测。每轮模型调用前检查对话加最多3段语音的保守估算能否容纳，再按实际请求分别预留；这项检查不是服务商账单封顶。

聊天“记忆”入口经用户确认后在本机保存、纠正或停用关联记忆，不调用模型。纠正/停用会让原消息及同轮回复退出后续上下文，停用的记忆也不再检索；若来源已合并进其他记忆，弹窗事先说明影响，修改或停用时也会停用包含它的合并记忆。预览与正式记忆不能互合；睡眠整理跳过显式聊天记忆及其合并派生，避免丢失来源控制。原聊天、修订记录和独立保存的资料仍保留，已发给服务商的请求不能收回。这是停止使用，不是数据删除或匿名化。

首次配置指南仅查询保存的路由、授权、启用状态、凭据是否存在及估算预算，不传回密钥值，不探测云端或调用模型。跳过状态保存在本机；新指南不会替用户确认人物资料的使用权。

2026-10-05修复：主聊天和历史搜索均隐藏voice_call逐句文字，仍保留通话卡片；文字继续在本机供模型上下文使用。取消“通话记录”导出会排除通话卡片、voice_call消息、sessions/turns及全部回复诊断副本。旧合成音频无法区分通话与试听，因此同时排除所有generated/audio文件；原始录音及按住说话的附件仍由音频选项控制。这不会删除本机数据，也不会清除用户另行写入的设定或记忆。


### 声音复刻费用估算（2026-10-05修正）

以下估价与调用前预算检查仅适用于统一服务中心的声音复刻能力路由，包括该路由下的阿里云连接。未配置该能力路由时，旧阿里云兼容连接仍可能被使用；它没有同等的单次人民币估价校验和剩余预算预检查。新配置应优先使用统一服务中心。

此前通用默认值1.5没有明确区分币种，不能直接作为人民币估价使用。大陆MiniMax官方端点现在默认按9.90元/音色估算；来源为[官方按量价格](https://platform.minimax.cn/docs/guides/pricing-paygo)。官方在首次使用复刻音色合成时收复刻费，本机为提前控制预算，在成功复刻时先计入该估算，不表示已经扣款；合成试听另计。

国际站、代理及其他服务不能套用大陆价格，须在高级配置cost_estimates.voice_clone填写单次人民币金额。用户明确配置的有效估价优先；拒绝负数、非有限值及云端复刻零估价。复刻上传前比较本次估算与日/月剩余预算，超出则拦截；已配置复刻路由不可用时不转入旧连接。此检查不是并发请求的原子费用预留，也不保证实际账单封顶。

本次仅修正统一服务中心的声音复刻默认估价和调用前预算检查，没有变更其他能力的计价策略；其他能力的缺省估算仍按各自文档边界使用，建议配置合理的单次人民币估价。
