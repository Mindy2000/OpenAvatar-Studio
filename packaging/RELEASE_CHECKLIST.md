# 发布检查清单

[English](RELEASE_CHECKLIST_EN.md) · [构建与发布](README.md)

## 源码公开前

- [ ] 检查实际提交清单和历史，不包含演示素材、个人数据、密钥、数据库、人物包或旧构建。
- [ ] 本机人物、导出、备份和凭据保持本地；自定义数据目录也被忽略。
- [ ] 使用经过检查的干净公开历史，不直接推送含旧演示的本机历史。
- [ ] 中英文版本、入口、隐私说明、人物包协议和模板与实现一致。
- [ ] 已知本地地址校验等安全限制已处理或准确披露；没有把文档更新当成代码修复。
- [ ] 配置 GitHub 私密漏洞报告并检查实际入口；安全政策没有虚构邮箱或不可用链接。
- [ ] 依照贡献指南完成测试、静态检查、浏览器/WebSocket 检查和依赖审计。
- [ ] 核对 Apache-2.0 及第三方/用户素材权利边界。

## 桌面包发布前

- [ ] 从干净源码在目标操作系统/架构重新构建；不复用旧安装包。
- [ ] 检查归档中没有本机数据、Key、绝对私有路径和不需要的产物。
- [ ] 项目 LICENSE 与随包第三方许可/声明齐全；校验文件正确。
- [ ] 各目标平台启动、停止、数据位置、凭据服务及证书验证通过。
- [ ] 从空数据库完成创建、导入、导出、预检和必要的媒体流程。
- [ ] 原始资料不会因测试而发往未授权服务；真实云端验收使用测试账号。
- [ ] 说明平台/架构、未签名状态、可选依赖、已验证范围和已知限制。
- [ ] 确认发布后才推送 `v*` 标签；标签工作流生成 Release 草稿，验收后再公开。
