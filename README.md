# OpenAvatar Studio

[GitHub 仓库](https://github.com/Mindy2000/OpenAvatar-Studio)

[English](README_EN.md) · [用户手册](docs/GUIDE.md) · [隐私与数据](docs/PRIVACY.md)

OpenAvatar Studio 是一个本地运行的数字人创建与管理工具。你可以用本人或明确授权的资料，或原创虚构设定，构建人格、记忆、声音、视觉身份和可编辑的世界，并连接自己的模型服务进行互动。

当前版本为 **0.1.0 发布候选**，适合本机体验和开发。源码不包含演示人物、个人数据库、API Key 或本地模型权重；首次使用从空人物列表开始。云端功能需要自己的服务账号，可能产生费用。

## 启动

需要 Python 3.11 或更新版本。下载源码并解压，进入项目目录：

- macOS：双击 `start.command`。
- Windows：双击 `start.bat`。
- Linux：执行 `chmod +x start.sh`，再执行 `./start.sh`。

脚本创建 `.venv`、安装依赖并启动本机服务，默认地址是 `http://127.0.0.1:8767`。首次安装需要联网。不要直接打开 `openavatar/static/index.html`。

若仓库 Releases 已提供对应平台的桌面包，可使用桌面启动器。桌面版会选择可用端口并打开浏览器；源码版与桌面版的数据位置不同，见[用户手册](docs/GUIDE.md)。不要将尚未发布的安装包视为可下载版本。

## 核心能力

- 真实素材与原创虚构两条创建路线，支持问答构建和文件导入。
- 人格编辑、证据记忆、世界事实与运行、聊天时间线的修改/封存/恢复。
- 统一服务中心：按能力配置服务、模型、数据授权、主备路由及估算预算。
- 文字流式聊天；声音转写、复刻、图片与异步视频生成取决于已配置服务。
- North/Atlas 实时视频通话与 LiveKit 连接。
- 视觉候选审批、连续性素材包、场景档案和视频关键帧验收。
- 人物包 v3 导入/导出，兼容 v1/v2；分别控制对话、音频、图片、视频和通话记录。
- 中英文界面资源、独立的人物语言及世界地区设置。

## 数据与当前限制

标准启动方式只监听本机回环地址。正常密钥字段保存在操作系统凭据库，源码发布不需要携带本机数据。人物包仍可能包含敏感资料，过滤导出不等于匿名化。

已选择并授权的云端 OCR 会在图片上传时调用；本地模型连接仅允许本机回环地址，并拒绝重定向。预算基于估算，不是服务商账单的硬上限。使用前请阅读[隐私说明](docs/PRIVACY.md)中的具体边界。
