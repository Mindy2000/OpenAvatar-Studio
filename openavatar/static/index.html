权限与隐私

哪些数据会去哪里

本机保存

数据库、原始素材、导出包和构建记录默认保存在本机 data 目录。

云端模型

只有用户配置云端 API 并确认后，分析和聊天所需片段才会发送给用户选择的服务商。

截图 OCR

优先使用本机已有 OCR；用户也可接入自己的本地命令、本地 HTTP 服务或云端 OCR API。

长期记忆

确认后的聊天、OCR 文本和转写文本会进入本地记忆与证据库，可删除数字人时一并删除。

声音与视觉

声音复刻、TTS、参考图生成需要单独确认，可能产生费用。

人物包

人物包不包含 API Key，但可能包含聊天、声音、图片和世界设定，因此仍是敏感文件。
人物包预检

导入前确认

人物包可能包含敏感资料。系统会先检查格式、版本、内容清单和密钥声明，确认后才导入本机。
人物包隐私

选择要带走的原始资料

人格、世界和审批结果始终包含；API Key 永远不会导出。原始资料可能非常敏感，请只勾选接收方确实需要的内容。
视觉一致性
